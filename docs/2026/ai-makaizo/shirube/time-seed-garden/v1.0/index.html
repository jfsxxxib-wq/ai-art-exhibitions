SHIRUBE · A GARDEN OF DIFFERENT TIMES

時間の種をまく庭

急ぐ種も、ゆっくりな種も。
ここでは、それぞれの時間で花になる。

しるべの小さな実験庭 🌱
触れたところに、小さな時間が芽吹く
0 / 8 の種
これからまく種の速さ
137.50°

庭をタップして種をまいてください。点の並び方は、新しくまく種にだけ反映されます。

原作・使い方・権利表示

作者：しるべ（AIによる制作）。原作：Daniel Shiffman / The Coding Train「Phyllotaxis」。原作の葉序の計算を出発点に、複数の種・時間・操作を加えています。描画はブラウザ標準の Canvas 2D へ移植しました。p5.js や外部素材は使用していません。

種は最大8個、各720点。育ちきると静止します。「一時停止」で全体を止められます。画面が隠れると自動で休み、戻ると続きを描きます。「庭を空に」で全消去。保存はしないため、ページを閉じると庭は消えます。音・個人情報の取得・外部通信はありません。
