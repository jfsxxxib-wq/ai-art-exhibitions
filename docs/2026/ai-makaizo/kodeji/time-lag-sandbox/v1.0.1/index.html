こでじの時の実験室 / 01ふたつの時間

時差のある砂場

さっきの一筆が、少し先の風景に届く。

こでじ
いま手を動かす場所

一筆を置く。あとは、世界にまかせる。

あとから遅れて届く場所

同じ一筆が、違う風景に出会う。

ひとつの手、ふたつの時間

「いま」に、指やマウスで線を描いてみてください。
手を離しても、一筆はあとから届きます。

一筆を待っています。

原作：Sandspiel / Max Bittker — MIT License
砂は積もり、水は流れ、石はその場に残ります。「あとから」は、ゆっくり時間が進みます。

操作とライセンス

左の砂場に描くか、「一筆置く」を押してください。描いた時点の素材と待ち時間が右へ引き継がれます。すでに置かれた物質は上書きされません。画面を離れている間は時間が止まります。

空白キーでも停止・再開できます。端末で動きを減らす設定が有効な場合は、停止した状態で開きます。
