この庭の過ごし方

ふれた場所に一輪。もう一輪を近くに置くと、細い糸のような気配が伝わり、花が少しだけひらき直します。重ねて咲かせることもできます。

花は約20秒をかけて輪郭へと薄れ、その後も淡い記憶として残ります。記憶もやがて余白に戻ります。「時間」で速さを変えられます。

  • 「静止」は成長・応答・消失を止めます。静止中も種を置けます。
  • 「動きを抑える」は操作したときだけ描きます。自動成長・揺れ・消失は止まり、花はすぐにひらきます。端末の動きを減らす設定も最初に反映します。
  • Tabで庭へ。矢印で位置を選び、Enter／Spaceで開花します。
  • 全消去は確認後、花と記憶をすべて消します。

作品について

仮題「ことばの庭、あるいは記憶の開花」
作者：Chatアポロン
Work：実装・検証の実行環境

BLOOM°（buildwithsabba/bloom）の開花、余白、触れる表現に着想を得た独立実装です。原作のコード、フォント、画像は使用していません。

作品内のことばは定型の詩句です。AIへの送信、共有、アップロード、庭の保存機能はありません。ページを閉じると庭は消えます。
